# 条形码识别工具 - 打包发布说明

## 快速打包

### Windows下使用批处理脚本

双击运行 `build-release.bat`，脚本会自动完成：
1. 清理旧的发布文件
2. 编译 Release 版本
3. 复制文件到发布目录
4. 创建 ZIP 压缩包

输出位置：
- 发布文件夹：`publish\BarcodeRenamer2_v1.0.0\`
- ZIP压缩包：`publish\BarcodeRenamer2_v1.0.0.zip`

---

## 手动打包方法

### 方法1：包含.NET运行时（推荐）

**优点**：无需安装.NET，直接运行
**缺点**：文件较大（约60-70MB）

```bash
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

输出目录：`bin\Release\net6.0-windows\win-x64\publish\`

---

### 方法2：不包含.NET运行时

**优点**：文件小（约1-2MB）
**缺点**：需要安装.NET 6.0 Runtime

```bash
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```

输出目录：`bin\Release\net6.0-windows\win-x64\publish\`

---

### 方法3：裁剪未使用的代码

**优点**：文件更小（约30-40MB）
**缺点**：可能裁剪掉必要的代码

```bash
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:PublishTrimmed=true
```

## 参数说明

### -c Release
指定使用 Release 配置，开启优化

### -r win-x64
指定目标平台为 Windows 64位

其他平台：
- `win-x86`: Windows 32位
- `win-arm64`: Windows ARM64
- `linux-x64`: Linux 64位
- `osx-x64`: macOS 64位

### --self-contained true
包含.NET运行时，无需安装.NET

### -p:PublishSingleFile=true
打包为单个可执行文件

### -p:PublishTrimmed=true
裁剪未使用的程序集，减小体积

### -p:IncludeNativeLibrariesForSelfExtract=true
将原生库包含在单文件中

## 优化建议

### 体积优化

1. 使用 PublishTrimmed（裁剪未使用代码）
2. 不包含.NET运行时（需要用户安装）
3. 使用 PublishReadyToRun（预编译优化）

```bash
dotnet publish -c Release -r win-x64 --self-contained true \
  -p:PublishSingleFile=true \
  -p:PublishTrimmed=true \
  -p:PublishReadyToRun=true
```

### 性能优化

1. 使用 Release 配置
2. 启用 PublishReadyToRun（启动更快）
3. 启用 TieredCompilation（运行时优化）

## 常见问题

### Q1: 打包后程序无法启动？

**原因**：缺少依赖文件
**解决**：使用 `--self-contained true` 包含所有依赖

### Q2: 打包文件太大？

**解决**：
- 使用 `PublishTrimmed=true` 裁剪未使用代码
- 使用 `--self-contained false` 不包含.NET运行时

### Q3: 发布后配置文件丢失？

**原因**：配置文件未复制
**解决**：手动复制 `appsettings.json` 到发布目录

### Q4: 托盘图标不显示？

**原因**：app.ico未复制到输出目录
**解决**：检查 `.csproj` 文件中的 `CopyToOutputDirectory` 设置

### Q5: 发布后识别准确率下降？

**原因**：使用了裁剪模式，可能裁剪了必要的代码
**解决**：不使用 `PublishTrimmed`，或添加裁剪保留配置

## 自动化发布

### GitHub Actions（可选）

创建 `.github/workflows/release.yml`：

```yaml
name: Release

on:
  push:
    tags:
      - 'v*'

jobs:
  build:
    runs-on: windows-latest
    steps:
    - uses: actions/checkout@v3
    
    - name: Setup .NET
      uses: actions/setup-dotnet@v3
      with:
        dotnet-version: 6.0.x
    
    - name: Publish
      run: dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
    
    - name: Create Release
      uses: softprops/action-gh-release@v1
      with:
        files: bin/Release/net6.0-windows/win-x64/publish/*
```
